# AI问数 - 企业级销售经管数据管理平台

一个企业级销售经管数据管理平台，核心能力为**数据问答**：用户以自然语言提问，平台完成数据查询、分析与可视化呈现。

当前仓库提供了一个已实现部分功能的前端原型（`index.html`），可直接在浏览器中打开预览。

## 面试任务

`index.html` 仅作为产品原型供参考，你需要自己新增代码来实现 demo 所示的完整功能，**不要改动该文件**。

请完成以下工作：

1. **功能分析** —— 阅读原型代码，理解各模块的职责与交互逻辑。
2. **问题诊断** —— 找出当前原型中存在的问题或不合理之处。
3. **功能实现** —— 根据界面布局与交互，推断并补全尚未完成的功能，让 demo 所示功能真正可用。

### 技术要求

- 前端：React
- 后端：Python
- 其余技术栈不限，开发过程使用的编程工具不限，使用的模型不限。
- 最终需要部署到 Linux 环境。

### 验收方式

1. 功能演示
2. Code Review

### 备注

- 不需要实现登录，以及用户管理相关内容。
- 语音转文字、文字转语音为可选项。
- text2sql 所需的数据（库表结构、示例数据、问句语料等）请自行准备。
