# 销售经营数据字典

固定演示数据使用 SQLite。金额以人民币分存储，返回结果注明元或万元。`NULL` 表示记录缺失或未知，零表示已记录的零金额。示例不引用真实企业台账。

| 表 | 粒度与关联 | 日期与金额 |
|---|---|---|
| `divisions` | 一个经营单元，主键 `id`，附地区 | 无金额 |
| `products` | 一个产品型号，主键 `id`，附产品线 | 原型重名的产品型号字段映射到标准字段 `model` |
| `contracts` | 一份合同，关联经营单元和产品，分别保存行业大类及行业 | `signed_on` 为签订日期，`gross_cents` 含税，`net_cents` 不含税，`is_solution` 为来源数据的商解标记 |
| `monthly_sales` | 同一合同在一个月份仅一行 | `period` 为统计月首日；`revenue_cents` 确认收入，`net_revenue_cents` 不含税确认收入，`paid_cents` 回款 |
| `annual_targets` | 一个经营单元的一个年度目标 | `commercial_cents` 商业目标，`solution_cents` 商解目标 |
| `projects` | 一个项目，可关联一份合同；项目 ID 去重 | `landed_on` 为落地日期，`risk` 为项目风险等级 |
| `dataset` | 每项基础台账的版本、截止日期 | `as_of` 使用 ISO 日期 |

合同趋势按签订日期归月，确认收入和回款按各自统计月汇总。商业完成率为不含税签约额除以商业目标，商解完成率为明确标记的商解合同之不含税确认收入除以商解目标。先聚合分子和分母，再按经营单元关联，防止目标因合同或收入记录重复累计。同比使用同时间范围，基期为零显示不可计算。商解识别、五类报表的完整业务口径及零或缺失目标的处理等待 Q01、Q02 确认。

在 `backend/` 中运行 `python -m app.seed` 初始化 `demo-1`。这个命令可以重复运行。

```sql
SELECT SUM(s.revenue_cents) FROM monthly_sales s JOIN contracts c ON c.id=s.contract_id
WHERE c.division_id='bj' AND s.period >= '2026-01-01' AND s.period < '2027-01-01';
-- 3000000000 分，即 3000 万元
SELECT COUNT(*) FROM projects WHERE risk='高风险';
-- 3 个项目
SELECT SUM(net_cents) FROM contracts WHERE division_id='bj' AND signed_on LIKE '2026-%';
-- 4800000000 分，与目标 6000000000 分比较为 80%
```
