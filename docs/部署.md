# Linux 容器部署

需要 Docker Engine 和 Docker Compose 2.24 或以上。默认只在本机 `127.0.0.1:8080` 访问演示服务。若配置默认 OpenAI 兼容模型，将模型地址、名称、密钥写入 `backend/.env` 中的 `AI_DEFAULT_MODEL_*`。模型地址使用公开 HTTPS，服务须支持 `/chat/completions` 及 `json_object` 响应格式。容器通过出站 HTTPS 访问模型。

在项目根目录执行：

```sh
docker compose config --quiet
docker compose up --build -d
docker compose ps
curl -fsS http://127.0.0.1:8080/api/health
```

打开 `http://127.0.0.1:8080`。四个页面与 `/api` 同源，直接访问 `/sys-model` 等页面地址时由 Nginx 回退到应用入口。首次启动安装 `demo-1` 数据，重复启动检查演示数据版本。会话、收藏、应用配置、反馈和加密密钥文件保存在 `ai-query-data` 卷。使用 `AI_MODEL_ENCRYPTION_KEY` 时，备份该环境值并在重建后保持一致。

持久化验收可在 Linux 环境进行。先创建会话、收藏问题、修改开场白，并对已成功查询的答案提交反馈。记录对应 ID 和标题，再执行：

```sh
docker compose restart
docker compose ps
curl -fsS http://127.0.0.1:8080/api/sessions
curl -fsS http://127.0.0.1:8080/api/favorites
curl -fsS http://127.0.0.1:8080/api/app-config
curl -fsS 'http://127.0.0.1:8080/api/feedbacks?page_size=5'
```

核对结果及页面状态，检查中文、时区、静态资源和刷新。调试可用 `docker compose logs backend frontend`，改动环境后用 `docker compose up -d --force-recreate backend frontend` 重新读取环境。正常停止使用 `docker compose stop`，保留数据卷。
