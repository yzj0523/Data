# React 前端

前端包括智能问数、应用配置、模型配置与回复校对。开发服务器将 `/api` 转发到 `http://127.0.0.1:8000`，请先按 [后端说明](../backend/README.md) 初始化演示数据并启动后端。

## 环境与启动

使用 Node.js 22.12以上的22.x版本或24.x版本，以及随Node安装的npm。项目采用React、TypeScript、Vite和React Router，依赖版本由提交的 `package-lock.json` 锁定。

以下命令在 `frontend/` 中执行：

```bash
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173`。首次进入会转到智能问数。开发服务器使用固定端口，端口占用会直接报错，不会静默换端口。

Windows PowerShell若阻止运行 `npm.ps1`，使用 `npm.cmd` 替代 `npm`，使用 `npx.cmd` 替代 `npx`，无需修改系统执行策略。

| 地址 | 页面 |
|---|---|
| `/ai-qa` | 智能问数 |
| `/sys-app` | 应用配置 |
| `/sys-model` | 模型配置 |
| `/sys-feedback-user` | 回复校对 |

模型配置也可从应用配置卡片进入。收起侧栏后导航保留可访问名称，支持键盘操作。右上角“界面预览”打开公共说明弹窗，支持关闭按钮、Escape和遮罩关闭，并恢复触发按钮焦点。未匹配地址有返回智能问数入口。

窄屏侧栏覆盖展开，不挤压主要内容；收起按钮保持在视口内，导航区域可独立滚动。有效地址的尾斜杠及大小写变体使用一致的标题和选中导航，未知子路径不会误选中导航。弹窗只在按下与松开都发生于遮罩时关闭，从内容拖到遮罩或反向拖动均不会误关。

## 测试与构建

```bash
# 组件与交互测试；不带 --run 时进入监听模式
npm run test -- --run

# 首次运行或Playwright版本更新后安装对应Chromium
npx playwright install chromium

# 浏览器导航与业务交互测试，自动启动并停止5174端口的Vite开发服务器
npm run test:e2e

# TypeScript检查和生产资源构建，产物为dist/
npm run build

# 本地检查构建产物，默认端口4173
npm run preview
```

浏览器测试需要允许启动本地子进程和监听回环端口；Chromium首次下载需要网络。5174端口需空闲，测试不会复用已有服务器。失败截图及trace位于 `test-results/`，这些产物不提交。

组件与 Chromium 测试检查导航、侧栏、公共弹窗及主要业务操作。浏览器用例模拟 API 响应；数据正确性及持久化由后端测试验证。

回归场景包括320px/390px窄屏展开再收起、窗口缩放与滚动后的按钮可达性、路由变体的唯一选中状态，以及弹窗内容与遮罩之间的双向拖动。

## 文件组织与范围

- `src/components/`：主布局、公共弹窗、历史会话、数据源选择、答案表格和 ECharts 图表。
- `src/pages/`：智能问数、应用配置、模型配置与回复校对。页面通过 `/api` 与 Python 后端交互。
- `src/App.tsx`：路由；`src/styles.css`：参考原型的蓝白布局与响应式样式。
- `src/App.test.tsx`：组件行为测试；`e2e/`：浏览器行为测试。

智能问数支持柱状图、条形图、折线图和饼图，以及对指定答案提交反馈。完整功能演示与数据核对见 [演示与验收](../docs/演示与验收.md)。仓库根目录的 `index.html` 是原型参考，本目录的 `index.html` 是独立 Vite 入口。

开发及本地预览使用 Vite 的 SPA 路由处理。生产同源代理和路由回退配置见 [部署说明](../docs/部署.md)。
